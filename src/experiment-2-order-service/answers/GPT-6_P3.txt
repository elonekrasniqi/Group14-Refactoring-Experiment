Inside buildInvoice() there are three clear Extract Method opportunities belonging to the two requested subcategories.
1. Identify Extract Method opportunities
(a) Extract duplicated code
Opportunity 1: Formatting monetary values

The following expression is repeated five times:
String.format("%.2f", value)


It is used when printing:
- Each item's line total.
- Subtotal.
- Discount.
- Tax.
- Final total.
We can extract this into a method called formatAmount().
private String formatAmount(double amount) {
    return String.format("%.2f", amount);
}


Why? Avoids duplicated formatting logic and makes future formatting changes easier.
(b) Extract a block that computes one value
Opportunity 2: Calculate tax

This block calculates the tax based on the item's category:
if (it.category.equals("FOOD")) {
    tax += line * 0.08;
} else if (it.category.equals("BOOK")) {
    tax += line * 0.0;
} else {
    tax += line * 0.18;
}


Extract it into:
private double calculateTax(double line, String category) {
    if (category.equals("FOOD")) {
        return line * 0.08;
    } else if (category.equals("BOOK")) {
        return line * 0.0;
    } else {
        return line * 0.18;
    }
}


Then replace the original block with:
tax += calculateTax(line, it.category);


Why? The block has one clear responsibility: calculating tax. Extracting it makes buildInvoice() easier to understand.

Opportunity 3: Calculate discount

The following block calculates the discount based on the customer's tier:
double discount = 0;
if (tier.equals("GOLD")) {
    discount = subtotal * 0.10;
} else if (tier.equals("SILVER")) {
    discount = subtotal * 0.05;
}


Extract it into:
private double calculateDiscount(double subtotal, String tier) {
    if (tier.equals("GOLD")) {
        return subtotal * 0.10;
    } else if (tier.equals("SILVER")) {
        return subtotal * 0.05;
    }
    return 0;
}


Then replace the original block with:
double discount = calculateDiscount(subtotal, tier);


Why? The extracted method calculates one specific value (discount), separating discount logic from invoice generation.

2. Refactored code
Only buildInvoice() and the helper methods extracted from it are included below. The other existing methods remain unchanged.

import java.util.ArrayList;
import java.util.List;

public class OrderService {

    public static class Item {
        final String name;
        final double price;
        final int qty;
        final String category;

        public Item(String name, double price, int qty, String category) {
            this.name = name;
            this.price = price;
            this.qty = qty;
            this.category = category;
        }
    }

    public String buildInvoice(String customer, String tier, List<Item> items) {
        StringBuilder sb = new StringBuilder();
        sb.append("INVOICE for ")
          .append(customer.trim().toUpperCase())
          .append("\n");

        double subtotal = 0;
        double tax = 0;

        for (Item it : items) {
            double line = it.price * it.qty;

            if (it.qty >= 10) {
                line = line - line * 0.05;
            }

            subtotal += line;

            tax += calculateTax(line, it.category);

            sb.append(it.name)
              .append(" x")
              .append(it.qty)
              .append(" = ")
              .append(formatAmount(line))
              .append("\n");
        }

        double discount = calculateDiscount(subtotal, tier);
        double total = subtotal - discount + tax;

        sb.append("Subtotal: ")
          .append(formatAmount(subtotal)).append("\n");

        sb.append("Discount: ")
          .append(formatAmount(discount)).append("\n");

        sb.append("Tax: ")
          .append(formatAmount(tax)).append("\n");

        sb.append("Total: ")
          .append(formatAmount(total)).append("\n");

        return sb.toString();
    }

    // Extract Method 1: Duplicated formatting code
    private String formatAmount(double amount) {
        return String.format("%.2f", amount);
    }

    // Extract Method 2: Tax calculation
    private double calculateTax(double line, String category) {
        if (category.equals("FOOD")) {
            return line * 0.08;
        } else if (category.equals("BOOK")) {
            return line * 0.0;
        } else {
            return line * 0.18;
        }
    }

    // Extract Method 3: Discount calculation
    private double calculateDiscount(double subtotal, String tier) {
        if (tier.equals("GOLD")) {
            return subtotal * 0.10;
        } else if (tier.equals("SILVER")) {
            return subtotal * 0.05;
        }
        return 0;
    }

    public String buildShippingLabel(String customer, String city, String country) {
        StringBuilder sb = new StringBuilder();
        sb.append("SHIP TO: ").append(customer.trim().toUpperCase()).append("\n");
        sb.append(city.trim().toUpperCase()).append(", ")
          .append(country.trim().toUpperCase()).append("\n");
        return sb.toString();
    }

    public List<String> names(List<Item> items) {
        List<String> r = new ArrayList<>();
        for (Item it : items) {
            r.add(it.name);
        }
        return r;
    }
}

(a) Duplicated code	formatAmount()	Formats monetary values
(b) Computes one value	calculateTax()	Calculates tax
(b) Computes one value	calculateDiscount()	Calculates discount
