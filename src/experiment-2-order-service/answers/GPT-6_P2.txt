The main goal of Extract Method is to take a group of statements that perform one specific task, move them into a separate method, and replace the original statements with a method call.

In this code, we can identify 6 good opportunities for Extract Method.
1. Refactoring opportunities
1. Extract customer name formatting
Original statements:
customer.trim().toUpperCase()


Extract into:
private String formatCustomerName(String customer) {
    return customer.trim().toUpperCase();
}


Why? Customer name formatting is a separate responsibility. It is also duplicated in buildInvoice() and buildShippingLabel().

Usage:
sb.append("INVOICE for ").append(formatCustomerName(customer)).append("\n");


2. Extract line price calculation
Original statements:
double line = it.price * it.qty;
if (it.qty >= 10) {
    line = line - line * 0.05;
}


Extract into:
private double calculateLineTotal(Item item) {
    double line = item.price * item.qty;

    if (item.qty >= 10) {
        line = line - line * 0.05;
    }

    return line;
}


Why? These statements calculate the final price of one item, including the quantity discount. This is a logically independent operation.
3. Extract tax calculation
Original statements:
if (it.category.equals("FOOD")) {
    tax += line * 0.08;
} else if (it.category.equals("BOOK")) {
    tax += line * 0.0;
} else {
    tax += line * 0.18;
}


Extract into:
private double calculateTax(Item item, double line) {
    if (item.category.equals("FOOD")) {
        return line * 0.08;
    } else if (item.category.equals("BOOK")) {
        return line * 0.0;
    } else {
        return line * 0.18;
    }
}


Why? Tax calculation is a separate business rule. Extracting it makes the main method easier to read and maintain.
4. Extract invoice item formatting
Original statements:
sb.append(it.name).append(" x").append(it.qty).append(" = ")
  .append(String.format("%.2f", line)).append("\n");


Extract into:
private void appendInvoiceItem(StringBuilder sb, Item item, double line) {
    sb.append(item.name).append(" x").append(item.qty).append(" = ")
      .append(String.format("%.2f", line)).append("\n");
}


Why? These statements are responsible for formatting one invoice line. Extracting them separates presentation logic from price calculations.
5. Extract customer discount calculation
Original statements:
double discount = 0;
if (tier.equals("GOLD")) {
    discount = subtotal * 0.10;
} else if (tier.equals("SILVER")) {
    discount = subtotal * 0.05;
}


Extract into:
private double calculateDiscount(String tier, double subtotal) {
    if (tier.equals("GOLD")) {
        return subtotal * 0.10;
    } else if (tier.equals("SILVER")) {
        return subtotal * 0.05;
    }

    return 0;
}


Why? Customer discount rules are independent of invoice generation. If discount percentages change, we only need to modify this method.
6. Extract invoice summary formatting
Original statements:
sb.append("Subtotal: ").append(String.format("%.2f", subtotal)).append("\n");
sb.append("Discount: ").append(String.format("%.2f", discount)).append("\n");
sb.append("Tax: ").append(String.format("%.2f", tax)).append("\n");
sb.append("Total: ").append(String.format("%.2f", total)).append("\n");


Extract into:
private void appendInvoiceSummary(
        StringBuilder sb,
        double subtotal,
        double discount,
        double tax,
        double total) {

    sb.append("Subtotal: ").append(String.format("%.2f", subtotal)).append("\n");
    sb.append("Discount: ").append(String.format("%.2f", discount)).append("\n");
    sb.append("Tax: ").append(String.format("%.2f", tax)).append("\n");
    sb.append("Total: ").append(String.format("%.2f", total)).append("\n");
}


Why? These statements have one responsibility: displaying the financial summary of the invoice.

2. Complete refactored code
Here is the complete class after applying Extract Method:

import java.util.ArrayList;
import java.util.List;

public class OrderService {

    public static class Item {
        final String name;
        final double price;
        final int qty;
        final String category;

        public Item(String name, double price, int qty, String category) {
            this.name = name;
            this.price = price;
            this.qty = qty;
            this.category = category;
        }
    }

    public String buildInvoice(String customer, String tier, List<Item> items) {
        StringBuilder sb = new StringBuilder();

        sb.append("INVOICE for ")
          .append(formatCustomerName(customer))
          .append("\n");

        double subtotal = 0;
        double tax = 0;

        for (Item it : items) {
            double line = calculateLineTotal(it);

            subtotal += line;
            tax += calculateTax(it, line);

            appendInvoiceItem(sb, it, line);
        }

        double discount = calculateDiscount(tier, subtotal);
        double total = subtotal - discount + tax;

        appendInvoiceSummary(sb, subtotal, discount, tax, total);

        return sb.toString();
    }

    // 1. Customer name formatting
    private String formatCustomerName(String customer) {
        return customer.trim().toUpperCase();
    }

    // 2. Calculate item price with quantity discount
    private double calculateLineTotal(Item item) {
        double line = item.price * item.qty;

        if (item.qty >= 10) {
            line = line - line * 0.05;
        }

        return line;
    }

    // 3. Calculate tax based on item category
    private double calculateTax(Item item, double line) {
        if (item.category.equals("FOOD")) {
            return line * 0.08;
        } else if (item.category.equals("BOOK")) {
            return line * 0.0;
        } else {
            return line * 0.18;
        }
    }

    // 4. Format one invoice item
    private void appendInvoiceItem(StringBuilder sb, Item item, double line) {
        sb.append(item.name).append(" x").append(item.qty).append(" = ")
          .append(String.format("%.2f", line)).append("\n");
    }

    // 5. Calculate customer discount
    private double calculateDiscount(String tier, double subtotal) {
        if (tier.equals("GOLD")) {
            return subtotal * 0.10;
        } else if (tier.equals("SILVER")) {
            return subtotal * 0.05;
        }

        return 0;
    }

    // 6. Format invoice financial summary
    private void appendInvoiceSummary(
            StringBuilder sb,
            double subtotal,
            double discount,
            double tax,
            double total) {

        sb.append("Subtotal: ").append(String.format("%.2f", subtotal)).append("\n");
        sb.append("Discount: ").append(String.format("%.2f", discount)).append("\n");
        sb.append("Tax: ").append(String.format("%.2f", tax)).append("\n");
        sb.append("Total: ").append(String.format("%.2f", total)).append("\n");
    }

    public String buildShippingLabel(String customer, String city, String country) {
        StringBuilder sb = new StringBuilder();

        sb.append("SHIP TO: ")
          .append(formatCustomerName(customer))
          .append("\n");

        sb.append(city.trim().toUpperCase())
          .append(", ")
          .append(country.trim().toUpperCase())
          .append("\n");

        return sb.toString();
    }

    public List<String> names(List<Item> items) {
        List<String> r = new ArrayList<>();

        for (Item it : items) {
            r.add(it.name);
        }

        return r;
    }
}



3. Before vs. After
Before refactoring	After refactoring
One long method	Smaller methods with clear responsibilities
Business logic mixed with formatting	Separate calculation and formatting
Difficult to identify individual operations	Each operation has a descriptive name
Repeated customer formatting	Reusable formatCustomerName()

4. Important concept for your exam
Remember this simple rule:

Extract Method = Select statements → Create a new method → Move statements → Replace them with a method call.

For example:
Before
double line = it.price * it.qty;
if (it.qty >= 10) {
    line = line - line * 0.05;
}



After
double line = calculateLineTotal(it);



New method
private double calculateLineTotal(Item item) {
    double line = item.price * item.qty;

    if (item.qty >= 10) {
        line = line - line * 0.05;
    }

    return line;
}



The key idea: We don't necessarily change what the program does. We change how the code is organized to make it easier to understand, reuse and maintain.
